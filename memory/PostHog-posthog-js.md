- Findings: `RequestQueue` stores queued requests in the private in-memory `_queue` array, batches them by route/group, and clears that array when formatting a flush.; `RetryQueue` likewise stores failed requests in a private in-memory `_queue` array. - Fix assessment: A durable queue changes delivery semantics across batching, retries, unload behavior, consent/persistence disabling, reset, storage failures, and potentially concurrent tabs.
