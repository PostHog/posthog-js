Move the default stylesheet inlining budget (10,000 rules) from the rrweb recorder into the posthog-js session recording options. The recorder chunk loads from an unversioned path, so cached or npm-pinned array.js bundles were getting the new budget with no way to change it: their config allowlist predates `inlineStylesheetBudgetRules`, so a user's override (including `0` to disable) was silently dropped while the behaviour change was live. The budget now only turns on when the posthog-js version that carries the option ships alongside the recorder, and direct `rrweb.record()` consumers get the previous unbounded inlining unless they opt in.

Deferred inlining is now bounded inside a sheet, not just between sheets. Previously each idle callback stringified one whole stylesheet, so a monolithic sheet produced one long task, relocated rather than shortened. A resumable cursor now stringifies 200 rules per slice, re-checks the `requestIdleCallback` deadline between slices (with spaced `setTimeout` ticks where idle callbacks are unavailable), and emits a sheet's `_cssText` mutation atomically only when its last slice completes, so partial CSS never reaches the wire.

Budget-deferred stylesheets no longer risk silently vanishing at teardown: the deferred queue is now flushed synchronously (with a bounded safety cap) when recording stops and on `pagehide`, and the SDK ships that pagehide-time flush with a matching drain of its compression queue and buffer. The `inlineStylesheetBudgetRules` docs now state the residual condition precisely: replay falls back to loading a deferred sheet from its original href (which may be purged, auth-gated, or renamed by replay time) only if the tab dies without `pagehide` firing, the teardown flush hits its safety cap, or stringifying the sheet fails; the last two cases are counted and exposed via `$sdk_debug_replay_deferred_stylesheets_failed` / `_abandoned`.

The budget no longer penalises pages whose CSS lives only in the CSSOM: rules from sources that can never be deferred (CSSOM-only `<style>` elements such as styled-components/Emotion `insertRule` output, and `adoptedStyleSheets`) no longer charge the inlining budget, since deferring `<link>` sheets buys those pages no freeze reduction. The telemetry now covers the gaps the review called out: the full-snapshot duration window wraps the whole synchronous `takeFullSnapshot` task (buffer unlock drain and document `adoptedStyleSheets` stringification included, and no longer misattributed to the mutation-batch timer), `$sdk_debug_replay_deferred_stylesheets` is cumulative for the session instead of read off the slowest snapshot, and new properties report the never-deferrable rule bucket (`$sdk_debug_replay_slowest_full_snapshot_css_rules_non_deferrable`) plus deferred idle-time stringification cost (`$sdk_debug_replay_deferred_stylesheet_ms` / `_slowest_slice_ms`). The duration gauges are also guarded against tab-suspension artifacts: a sample whose measurement window straddles a `visibilitychange`/`freeze`/`resume` boundary, or whose synchronous window exceeds a 60-second plausibility cap (a suspended renderer's wall clock spans the sleep, producing readings of minutes or more), is discarded rather than recorded, with the discard count exposed as `$sdk_debug_replay_discarded_duration_samples`.
